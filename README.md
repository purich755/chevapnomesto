# Чевапно Место — демо-сайт

Премиальный одностраничник сербского бистро «Чевапно Место» (Самара).
Собран целиком на фирменных материалах клиента: брендбук `Chevapno_Mesto_1.pdf`
и папка `Элементы к сайту`. Ни одного стороннего шрифта, фото, иконки или стока.

Чистый HTML + CSS + vanilla JS. Сборщика нет. GSAP лежит локально в `js/vendor/`.

---

## Как запустить

Любой статический сервер из корня проекта. Например:

```bash
python -m http.server 8310
```

Дальше открыть <http://localhost:8310>.

Просто дважды кликнуть по `index.html` не получится: браузер заблокирует
загрузку шрифтов по `file://`.

## Что где лежит

```

data/prosek.json      ⬅ меню точки на 5-й Просеке (правится в admin.html)

admin.html, js/admin.js  админка этого меню
js/main.js            сборка страницы и анимации
js/vendor/            GSAP 3.15 + ScrollTrigger + SplitText (локально, без CDN)
assets/img/           фоны, логотипы, графэлементы, фото
assets/img/dish/      фото блюд, вырезанные с меню-бордов клиента

```

## Страница меню 5-й Просеки и админка

`menu.html` — меню отдельной точки: **5-я Просека, 95а**. Там мангал, пицца
и основное меню, плюс «Самовывоз и доставка: +7 (987) 939-30-13». Пивные
закуски с борда клиента на эту страницу не входят. Главная остаётся со своим
меню по бордам 07-10, на точку ведут кнопки в разделе меню и в «Найди нас».

Данные страницы лежат в **`data/prosek.json`**. Их правят через
**`admin.html`** (адрес: `…/chevapnomesto/admin.html`):

- раскрыть раздел → поправить название, вес, цену прямо в строке;
  по стрелке ▾ — уточнение, состав, «острое», варианты с разными ценами
  (25/30 см, 5/9 шт), фото, порядок, копия, удаление;
- «+ Добавить блюдо», «+ Добавить раздел», «+ гарнир на выбор»;
- фото можно загрузить с телефона: оно ужимается до квадрата 800 px в WebP;
- «Предпросмотр» открывает меню с черновиком, посетители его не видят;
- «Опубликовать» отправляет одним коммитом JSON и новые фото
  (в `assets/img/menu/`). GitHub Pages обновляет сайт примерно за минуту,
  админка сама сообщает, когда изменения появились на сайте.

Черновик сохраняется в браузере сам. Без названия или цены опубликовать
нельзя: такие поля подсвечиваются.

**Вход.** Нужен ключ GitHub (fine-grained personal access token):
Repository access → только `chevapnomesto`, Permissions → Contents: Read and
write. Ключ хранится только в браузере (по умолчанию до закрытия вкладки,
с галочкой «Запомнить» — постоянно). Без ключа админку можно открыть
в режиме просмотра и черновика.

## Где менять контент

Главная страница — **`js/content.js`** (меню на 5-й Просеке — в админке, см. выше).

| Что | Где в файле |
|---|---|
| Адрес, часы, телефон, соцсети | `CONTACTS` |
| Цифры и ссылки блока доставки | `CONTACTS.delivery` |
| Меню: категории, блюда, цены, состав | `MENU` |
| Карточки горизонтальной витрины | `SHOWCASE` |
| Гарниры и ланчи | `LUNCH_SIDES`, `LUNCH_MAINS`, `LUNCH_NOTE` |
| Тексты бегущих строк | `MARQUEE_TOP`, `MARQUEE_BOTTOM` |

Поля блюда: `id` — имя файла в `assets/img/dish/`, `name`, `sub` — уточнение,
`w` — граммовка, `p` — цена, `hot: true` — метка «остро», `d` — состав,
`opts` — варианты одной позиции `[подпись, граммы, цена, остро?]`
(пита-плескавица, траке, гамбори, фри).

Строки, которые надо согласовать с клиентом, помечены в файле `// ⚠ уточнить`.

## Как соблюдён брендбук

- **Три цвета и только они:** `#F03E1E`, `#210803`, `#FFFFFF` и их прозрачные
  производные. Графэлементы клиента приехали в чужом цветовом профиле
  (красный был `210,57,47`) — скрипт подготовки приводит их к точному `#F03E1E`.
- **Два шрифта:** Arkhip на всех заголовках (кернинг −6 %, интерлиньяж 0.95),
  TikTok Sans SemiBold на наборном тексте (−3 %). Подключены локально.
- **Заголовки секций одного кегля** по всей странице — прямое правило гайда.
  Разный размер только у цифр: цен, граммовок, номеров секций, времени.
- **Логотип:** только готовые PNG, без наклонов, эффектов и теней, межбуквенное
  расстояние не тронуто, знак не масштабируется отдельно от текста, вокруг лого
  оставлено охранное поле. Единственное вращение — у штампа: гайд разрешает.
- **Фото на тёмном.** Снимки на белом фоне (`1.jpg`, `15.jpg` и др.) и все
  блюда с меню-бордов вырезаны по маске и лежат на фирменной тёмной подложке
  с зерном — как требует раздел про изображения «на чёрном фоне и с дымом».
- **Паттерн не тайлится:** `Фон-*` ставятся цельным полотном на секцию.

## Анимации

| Приём | Где |
|---|---|
| Заставка «Розжиг»: искры, знак пламени заливается красным по мере загрузки, проявляется логотип, экран расходится по фирменной диагонали | старт |
| Живые угли: поле искр на канвасе, крутится само по себе | секция 03 |
| Штамп-печать вращается сам по себе, медленно и непрерывно | секция 02 |
| Pinned-горизонтальная витрина | секция 04 |
| Reveal заголовков по маске + `y: 40 → 0`, 0.7 с, `cubic-bezier(.16,1,.3,1)` | все секции |
| Каскад карточек (stagger 0.05–0.08 с) | сетки |
| Параллакс фонов и фото | 01, 02 |
| Бегущие строки, скорость растёт от скорости скролла | полосы огня |
| Пламя-индикатор прокрутки вместо прогресс-бара | глобально |
| Счётчики цифр | цены, ланч, доставка |
| Magnetic hover (до 6 px) | кнопки |
| Надрыв стикера-пломбы | секция 07 |
| Диагональный рез секций `clip-path` | 05, 06, 08 |

Анимируются только `transform` и `opacity`.

### Секция 03 — «живые угли»

Секция построена целиком процедурно, без видео и без картинок — только два
фирменных цвета. На канвасе живёт поле искр: частицы рождаются у нижнего края,
поднимаются с лёгким покачиванием, мерцают и гаснут, аддитивно светятся
красным и белым. Огонь крутится сам по себе (`gsap.ticker`), независимо от
прокрутки — «огонь, который не гаснет». Снизу — красное зарево углей, за
искрами еле дышит крупный фирменный знак пламени.

Прокрутка управляет только тремя словами `ОГОНЬ → ВКУС → МЕСТО` (blur → фокус →
scale + fade) и слегка «раздувает» интенсивность искр к концу секции.

При `prefers-reduced-motion` канвас не запускается: остаётся статичное зарево,
а три слова просто показаны без анимации.

### Заставка «Розжиг»

Тоже без видео: на канвасе летят искры, знак пламени заливается красным снизу
вверх, счётчик бежит 0 → 100, подпись меняется «Разжигаем угли → Жарим
плескавицу → Печём питу». Последние проценты ждут шрифтов и картинок первого
экрана, поэтому счёт не врёт. На 100 знак сменяется полным логотипом, по
фирменной диагонали проходит красный рез, и экран расходится на две половины.
В той же вкладке повторно показывается короткая версия (флаг в `sessionStorage`).
Старая заставка на видео — в метке `pered-zastavkoy`.

## Пересборка ассетов

Скрипт тянет исходники из `G:\Чевапно место пос материалы\Элементы к сайту`
(путь переопределяется переменной `CHEVAPNO_SRC`), а борды меню 07-10 —
из папки «Загрузки» (переменная `CHEVAPNO_BOARDS`).

```bash
python tools/build_assets.py
```

Отдельные шаги: `fonts`, `bg`, `logo`, `elem`, `photo`, `dishes`, `contact`.
Например `python tools/build_assets.py dishes contact`.

Нужны `pillow`, `numpy`, `scipy` и `fonttools[woff]`.

Что делает скрипт:

- `.ttf → .woff2`;
- `Фон-1…11` — ресайз до 1920 px, WebP q80, плюс зерновые плитки;
- логотипы ≤ 1600 px, графэлементы ≤ 1200 px, прозрачность сохранена,
  цвета приведены к фирменным;
- фото клиента ≤ 2000 px, WebP + JPG-fallback, версии с убранным белым фоном;
- **нарезка 52 блюд с меню-бордов**: для каждого блюда строится маска
  (фон борда — гладкий градиент, еда — текстурная), блюдо вырезается по ней и кладётся в квадрат 680×680 с прозрачным фоном;

Шаг `contact` собирает `tools/dish-contact.jpg` — контрольный лист всех
нарезанных блюд, чтобы глазами проверить кропы после правки координат
в словаре `DISHES`.

## Самопроверка в браузере

```bash
python tools/shots.py
```

Снимает десктоп (1440×900) и мобайл (390×844) по всем секциям
в `tools/shots/`, попутно печатая ошибки консоли. Нужен `playwright`
с установленным chromium и запущенный сервер на 8310.

Отдельные кадры: `python tools/shots.py desktop hero menu`.
