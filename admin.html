Вход

Чтобы публиковать изменения, нужен ключ доступа к репозиторию сайта на GitHub. Его выдаёт разработчик.

Где взять ключ
  1. Владелец репозитория открывает github.com → Settings → Fine-grained tokens.
  2. Repository access: Only select repositories → chevapnomesto.
  3. Permissions → Repository → Contents: Read and write. Больше ничего не нужно.
  4. Нажать Generate и вставить ключ сюда.
